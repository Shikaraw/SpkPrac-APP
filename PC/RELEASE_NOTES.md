## SpkPrac for Windows v1.0.0

Android 版 `SpkPrac` 的 Windows 桌面移植版 —— 全双工实时语音对话 + AI 口语练习。
**单文件 exe，3.97 MB**，无需安装程序、无需运行库（使用系统自带 WebView2）。

### 下载
下载 `SpkPrac-1.0.0.exe`，双击运行即可。

> 未做代码签名，首次运行 Windows SmartScreen 可能提示「未知发布者」，
> 点「更多信息 → 仍要运行」即可。

### 功能

**对话**
- 实时语音对话，服务端 VAD 自动断句；也支持按住说话（PTT）
- 允许打断：你一开口 AI 立刻停，本地播放缓冲同步清空
- 断线自动重连（最多 3 次，指数退避），重连后重放最近 40 条上下文
- 实时字幕、实时翻译、会话计时、轮数统计、麦克风电平波形

**口语练习**
- 15 种语言 × 4 档 CEFR 水平，8 个快捷话题
- 纠错策略三档（不纠错 / 偶尔 / 经常）
- 结束后生成 Markdown 练习报告，可复制、可重新生成

**历史与数据**
- 会话自动落盘，首页展示次数 / 累计时长 / 连续天数
- 搜索、二次确认删除、详情页导出 Markdown
- 一键导出全部会话到「文档\SpkPrac」

**外观**
- 深色 / 浅色 / 跟随系统，原生标题栏同步
- 中英双语、字幕字号三档、动效总开关
- Aurora 流光背景、Canvas 手写语音球、气泡进场动画

**桌面版增强**
- 麦克风与扬声器可分别选择，插拔后可在会话中切换
- 自动/手动检查更新，GitHub 不可达时自动走镜像

### 技术栈
Tauri v2 + Rust + 原生 Web 前端 + Web Audio API。
音频走 WebView2（拿到 Chromium 的系统级回声消除），网络走 Rust（能设置鉴权头）。

### 已知限制
- 未做代码签名
