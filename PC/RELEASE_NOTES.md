## 新增：选中文本 → 翻译 / 问 AI

在会话页或会话详情里，**选中一个词或一段话**，会浮出一个小工具条：

- **翻译** —— Android 优先交给系统的文本处理/翻译应用；系统里没有可用应用时自动回退到 AI 翻译。
  Windows 直接用文本模型翻译。
- **问 AI** —— 把选中的文本发给已配置的文本模型，让它解释用法、给例句，结果以 Markdown 展示，可复制。

没配置文本模型时会明确提示，不会静默失败。

## 新增：搜索历史对话内容

首页搜索框以前只能搜标题和语言，现在**能搜到对话正文**。
命中内容时，会话下方会显示一行灰色的匹配片段，方便判断是不是想找的那段。

## Android：练习中保持在线

练习期间通知栏常驻一条「练习中」通知，带系统计时器：

- 切到后台、锁屏都不会中断会话
- 点通知直接回到练习界面
- 结束练习后通知自动消失

首次进入会话时会申请通知权限；**即使拒绝，练习也照常进行**，只是不显示通知。

## 修复：Android 版本更新检查失效

这是一个**实际存在的线上问题**。仓库同时发布 Windows 版（tag 前缀 `pc-v`），
而 GitHub 的 `/releases/latest` 按发布时间选「最新」，不是按平台。

Windows 版 1.2.0 发布后，它变成了「latest」，于是：

- Android 端拿到的是 `pc-v1.2.0`，解析出的版本号被判定为"更旧"
- **装着 1.1.0 的 Android 用户收不到 1.2.0 的更新提示**

现在改为拉取 release 列表，只认 `v*` 且显式排除 `pc-v*`，取第一个符合的。
已用线上真实数据验证：新逻辑正确选中 `v1.2.0`（APK），旧逻辑拿到的是 `pc-v1.2.0`（exe）。
